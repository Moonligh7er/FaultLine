## How to run

```bash
node scripts/open311/verify-integration.mjs
```

The script is read-only (GET probes only, no submissions). It writes:

- `scripts/open311/integration-status.json` — machine-readable report
- `docs/integration-status.md` — this file, replaced on each run

To point at a different markdown output:

```bash
node scripts/open311/verify-integration.mjs --output some/other/path.md
```
