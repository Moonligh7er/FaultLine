If the marketing site itself is down, this page is not reachable either. For a truly independent status source, an external uptime service (Better Stack, UptimeRobot) is required — see the changelog for the current infra roadmap.

What the tiers mean: Critical failures make the platform unusable for users. Critical · backend failures break background pipelines (escalation, cron) without affecting the app shell. Degrades gracefully services have fallbacks — if they’re down, the app still works with reduced capability. Reference targets are third-party pages Fault Line links out to; if they’re down, the links 404 for recipients.
